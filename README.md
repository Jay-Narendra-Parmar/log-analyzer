# Log Analyzer

A command-line tool for analyzing web server logs.

## Requirements

- Python 3.12 or newer

## Project layout

- `src/log_analyzer/` - application package
- `tests/` - automated tests
- `data/` - sample or input data
- `scripts/` - development and utility scripts
- `docs/` - project documentation

The package and its commands will be added as their implementation is developed.
